# Python CLI / GUI Calculator
A simple calculator built with Python and Tkinter

## About
This is a beginner Python project created to practice graphical user interface (GUI) development and fundamental programming concepts.
The calculator interface is inspired by a standard mobile calculator

## Features
* Graphical user interface using Tkinter
* Number input
* Decimal input
* Clear (`AC`)
* Positive/negative toggle (`+/-`)
* Percentage (`%`)
* Calculator operation buttons
* Styled calculator interface
* Centered application window

## Technologies Used
* Python
* Tkinter

## Current Status
The project is currently under development. Basic number input and several calculator controls are implemented, while some arithmetic operations are still being developed

## How to Run
Make sure Python is installed on your computer
Run the following command:
```
python simpleCalculator.py
```
The calculator window should open automatically
